# Sede de Nuvem

Jogo de tabuleiro digital para discutir dilemas éticos sobre sustentabilidade, consumo de água e energia e inteligência artificial no Pecém, Ceará.

## Jogar com outras pessoas

A partida online permite de 2 a 4 jogadores. Todos precisam de internet e devem abrir o mesmo link.

1. Toque em **Online**.
2. O anfitrião informa nome e papel e escolhe **Criar sala**.
3. Compartilhe o código da sala com os outros jogadores.
4. Os demais escolhem **Entrar com código** e digitam o código.
5. Quando houver pelo menos 2 participantes, o anfitrião escolhe **Iniciar partida**.

O anfitrião também pode usar **Copiar código e link** na sala para enviar o convite.

## Como funciona

A equipe percorre um tabuleiro de 45 casas, resolve cartas de dilema e evidência, usa power-ups e realiza entregas. Todos acompanham os indicadores coletivos de água, energia, licença social e desenvolvimento. As decisões exploram temas como consulta prévia, transparência de dados, impacto ambiental e efeito rebote da eficiência.

## Tecnologias

- HTML, CSS e JavaScript
- Firebase Authentication com login anônimo
- Firebase Realtime Database para sincronizar salas e partidas
- GitHub Pages para hospedar o jogo

## Observação sobre a demonstração

Este é um protótipo acadêmico. Para testes, use apelidos e não informe dados pessoais. A sala online depende das regras de segurança configuradas no Firebase; uma mensagem **“Permissão negada”** indica que o banco está bloqueando o acesso.
